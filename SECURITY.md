# Security

The theme is CSS and a manifest. It has no script, and it does not read or send data. The `scripts/` folder is for the people who work on the theme and does not run inside Obsidian.

## Report a problem

If you find a way to harm a user with the files of this repo, report it through the Security tab of the repo, with "Report a vulnerability". If that button is not there, open an issue that says you have a security report and gives no details. The maintainer then gives you a private way to send it.

## Which versions get a fix

The newest release gets a fix.
