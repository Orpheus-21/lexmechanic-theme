# Code of conduct

This project is open to everyone. We want a place where people can ask, report, and build in peace.

## What we expect

* Be polite. Talk about the work, not the person.
* Accept that people have different levels of skill and different needs.
* Give feedback that the other person can use.
* Do not harass anyone. Do not use insults or slurs. Do not publish private information.

## What happens when someone breaks these rules

The maintainer can edit or delete comments, close issues and pull requests, and block a person from the repo. The maintainer decides what is enough for each case.

## How to report a problem

Use the "Report content" link on the comment on GitHub, or contact the maintainer through the GitHub profile https://github.com/Orpheus-21. The maintainer reads each report and keeps it private.

## Where this applies

This applies to the issues, pull requests, and discussions of this repo, and to the places where a person speaks for the project.
